# Sambang Zakat Gresik — Lab Imersif Filantropi Islam (VR · AR · GenAI)

Media pembelajaran mata kuliah **Filantropi Islam** (Prodi PAI, Universitas Sunan Gresik).
Pengguna "sambang" (berkunjung) ke enam lapak Pasar Bandeng Gresik dalam dunia 3D, menganalisis dan menghitung zakat, lalu menyalurkannya ke 8 asnaf, dibimbing tutor AI "Bu Nyai Tika".

## Cara menerbitkan di GitHub Pages (± 5 menit, gratis)
1. Masuk ke https://github.com, lalu klik **New repository**. Beri nama misalnya `sambang-zakat` dan atur ke **Public**.
2. Klik **Add file → Upload files**, unggah `index.html` (dan README.md ini), lalu klik **Commit changes**.
3. Buka **Settings → Pages**. Pada *Build and deployment* pilih **Deploy from a branch**, branch `main`, folder `/ (root)`, lalu klik **Save**.
4. Tunggu 1–2 menit. Link publik akan muncul: `https://NAMA-AKUN.github.io/sambang-zakat/`

## Fitur di GitHub Pages
- **VR**: dunia 3D WebXR (A-Frame 1.6). Di ponsel Android/headset, tombol kacamata VR muncul di kanan bawah.
- **AR**: kamera belakang langsung aktif (izinkan akses kamera). Di Android Chrome yang mendukung WebXR, tersedia juga tombol AR imersif.
- **GenAI**: memakai Puter.js (gratis, tanpa API key). Saat fitur AI pertama kali dipakai, pengguna diminta masuk/daftar akun Puter sekali. Bila tidak tersedia, aplikasi otomatis beralih ke mode luring.

Acuan angka: SK Ketua BAZNAS No. 14/2026 (zakat fitrah) dan No. 15/2026 (nisab zakat penghasilan). Harga emas di kasus bersifat asumsi.
